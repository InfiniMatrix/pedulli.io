安全

公开站点上没有源代码。

浏览器只接收预先构建的 HTML、CSS 和 JavaScript。源代码、构建脚本、调试数据和实现元数据均保持私有；不分发任何可执行的编解码器。

静态站点

GitHub Pages 只提供文件。没有服务器代码、数据库、登录或密钥。

客户端无编解码器

公开站点上不存在可执行的压缩器、模型、primer 或权重。

不透明的错误信息

只显示通用信息——不含版本、级别、路径或链元数据。

OWASP ASVS（自评对照）

V1 架构、设计与威胁建模 · V5 验证、净化与编码 · V7 错误处理与日志 · V8 数据保护 · V9 通信 · V10 恶意代码 · V12 文件与资源 · V14 配置。V2 身份验证、V3 会话管理、V4 访问控制、V6 存储加密和 V13 API 不适用：公开站点上没有登录、会话、受保护资源、静态数据或服务器 API。 这是对照 ASVS 4.0 的自评映射，不是认证，也不是独立审计；对照 ASVS 5.0.0 的复核尚未完成。

NIST SP 800-218 SSDF v1.1

准备：明确安全要求和角色。保护：私有源代码仓库、固定的工具链、去除符号的可复现构建，无 source map 和调试路由。生产：记录 SHA-256 关卡，并在发布前评审。响应：保全证据、记录负面结果，并提供私密的漏洞报告渠道。

NIS2

不声称符合 NIS2 或获得相关认证。是否适用及相关义务取决于法律实体、行业和部署方式。

坦诚的局限

任何客户端代码或编译模块都无法完全防止逆向工程。去除符号会提高成本，但不能使分析变得不可能。可以确保的是：公开站点上不存在源代码。

GitHub Pages 免费版会忽略 _headers，因此无法在那里设置 HTTP 安全头。已包含基于 meta 的 CSP，但只是部分防护。锁定的静态演示不会上传任何文件。
