セキュリティ

公開オリジンにソースコードはありません。

ブラウザが受け取るのはビルド済みの HTML、CSS、JavaScript のみです。ソースコード、ビルドスクリプト、デバッグデータ、実装メタデータは非公開で、実行可能なコーデックは配信しません。

静的オリジン

GitHub Pages はファイルを配信するだけです。サーバーコード、データベース、ログイン、シークレットはありません。

クライアント側コーデックなし

公開オリジンには、実行可能な圧縮器、モデル、プライマー、重みのいずれも存在しません。

不透明なエラー

表示されるのは汎用メッセージのみで、バージョン、レベル、パス、チェーンのメタデータは含みません。

OWASP ASVS (自己評価による対応付け)

V1 アーキテクチャ・設計・脅威モデリング · V5 検証・無害化・エンコーディング · V7 エラー処理とログ · V8 データ保護 · V9 通信 · V10 悪意のあるコード · V12 ファイルとリソース · V14 構成。V2 認証、V3 セッション管理、V4 アクセス制御、V6 保存時の暗号、V13 API は対象外です。公開オリジンにはログイン、セッション、保護リソース、保存データ、サーバー API がありません。 これは ASVS 4.0 に対する自己評価の対応付けであり、認証や独立監査ではありません。ASVS 5.0.0 に基づく見直しは未完了です。

NIST SP 800-218 SSDF v1.1

準備: セキュリティ要件と役割を定義。保護: 非公開のソースリポジトリ、固定したツールチェーン、シンボルを除去した再現可能なビルド、ソースマップやデバッグ経路なし。生産: SHA-256 ゲートを記録し、昇格前にレビュー。対応: エビデンスの保全、否定的結果のログ、非公開の報告窓口。

NIS2

NIS2 への準拠や認証は主張していません。適用の有無と義務は、法人、業種、導入形態によって決まります。

正直な限界

クライアント側のコードやコンパイル済みモジュールで、リバースエンジニアリングが不可能なものはありません。シンボル除去はコストを上げますが、解析を不可能にはしません。守れる性質は、公開オリジンにソースコードが存在しないことです。

GitHub Pages の無料プランは _headers を無視するため、HTTP のセキュリティヘッダーを設定できません。meta による CSP を含めていますが部分的です。ロックされた静的デモはファイルをアップロードしません。
