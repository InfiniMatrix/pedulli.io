Bezpieczeństwo

Brak kodu źródłowego w publicznym serwisie.

Przeglądarka otrzymuje wyłącznie zbudowane wcześniej HTML, CSS i JavaScript. Kod źródłowy, skrypty budowania, dane debugowania i metadane implementacji pozostają prywatne; nie jest dostarczany żaden wykonywalny kodek.

Statyczny serwis

GitHub Pages serwuje tylko pliki. Nie ma kodu serwera, bazy danych, logowania ani sekretów.

Brak kodeka po stronie klienta

W publicznym serwisie nie ma wykonywalnego kompresora, modelu, primera ani wag.

Nieprzejrzyste błędy

Wyświetlane są tylko ogólne komunikaty — bez wersji, poziomu, ścieżki ani metadanych łańcucha.

OWASP ASVS (samoocena)

V1 Architektura, projekt i modelowanie zagrożeń · V5 Walidacja, sanityzacja i kodowanie · V7 Obsługa błędów i logowanie · V8 Ochrona danych · V9 Komunikacja · V10 Złośliwy kod · V12 Pliki i zasoby · V14 Konfiguracja. V2 Uwierzytelnianie, V3 Zarządzanie sesją, V4 Kontrola dostępu, V6 Przechowywana kryptografia i V13 API nie mają zastosowania: w publicznym serwisie nie ma logowania, sesji, chronionych zasobów, danych w spoczynku ani API serwera. To samodzielnie przygotowane mapowanie względem ASVS 4.0, a nie certyfikacja ani niezależny audyt; przegląd względem ASVS 5.0.0 jest w toku.

NIST SP 800-218 SSDF v1.1

Przygotowanie: zdefiniowane wymagania i role bezpieczeństwa. Ochrona: prywatne repozytorium kodu, przypięty toolchain, odtwarzalne buildy bez symboli, brak source map i tras debugowania. Wytwarzanie: zapisane bramki SHA-256 i przegląd przed promocją. Reagowanie: zabezpieczanie dowodów, rejestr wyników negatywnych i prywatny kontakt do zgłoszeń.

NIS2

Nie deklarujemy zgodności ani certyfikacji NIS2. Zastosowanie i ewentualne obowiązki zależą od podmiotu prawnego, sektora i wdrożenia.

Uczciwe ograniczenia

Żaden kod po stronie klienta ani skompilowany moduł nie jest odporny na inżynierię wsteczną. Usunięcie symboli podnosi koszt, ale nie uniemożliwia analizy. Obronną właściwością jest brak kodu źródłowego w publicznym serwisie.

GitHub Pages w darmowym planie ignoruje _headers, więc nie można tam ustawić nagłówków bezpieczeństwa HTTP. Dołączono częściową politykę CSP w znaczniku meta. Zablokowane statyczne demo nie wysyła żadnych plików.
