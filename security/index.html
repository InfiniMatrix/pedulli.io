Security

No source on the public origin.

The browser receives only prebuilt HTML, CSS and JavaScript. Source, build scripts, debug data and implementation metadata stay private; no executable codec is shipped.

Static origin

GitHub Pages serves files only. There is no server code, database, login or secret.

No client codec

No executable compressor, model, primer or weights are present on the public origin.

Opaque errors

Only generic messages are shown — no version, level, path or chain metadata.

OWASP ASVS (self-assessed mapping)

V1 Architecture, Design and Threat Modeling · V5 Validation, Sanitization and Encoding · V7 Error Handling and Logging · V8 Data Protection · V9 Communications · V10 Malicious Code · V12 Files and Resources · V14 Configuration. V2 Authentication, V3 Session Management, V4 Access Control, V6 Stored Cryptography and V13 APIs are not applicable: there is no login, session, protected resource, data at rest or server API on the public origin. This is a self-assessed mapping against ASVS 4.0, not a certification or an independent audit; a review against ASVS 5.0.0 is pending.

NIST SP 800-218 SSDF v1.1

Prepare: defined security requirements and roles. Protect: private source repository, pinned toolchain, stripped reproducible builds, no source maps or debug routes. Produce: recorded SHA-256 gates and review before promotion. Respond: evidence preservation, negative-result log and a private disclosure contact.

NIS2

No NIS2 compliance or certification is claimed. Applicability and any obligations depend on the legal entity, the sector and the deployment.

Honest limits

No client-side code or compiled module is impossible to reverse engineer. Stripping raises the cost; it does not make analysis impossible. The defensible property is that no source code is present on the public origin.

GitHub Pages ignores _headers on the free tier, so HTTP security headers cannot be set there. A meta CSP is included and is partial. No file is uploaded by the locked static demo.
