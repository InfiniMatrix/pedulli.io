Seguridad

Sin código fuente en el origen público.

El navegador recibe solo HTML, CSS y JavaScript preconstruidos y un módulo WebAssembly sin símbolos. Fuentes, scripts de compilación, depuración y metadatos permanecen privados.

Origen estático

GitHub Pages sirve solo archivos; sin código de servidor, base de datos, login ni secretos.

Módulo sin símbolos

El WebAssembly no tiene secciones de depuración, sección de nombres ni metadatos producers.

Errores opacos

Solo mensajes genéricos — sin versión, nivel, ruta ni cadena.

OWASP ASVS 4.0

V1 Arquitectura y modelado de amenazas · V5 Validación y codificación · V7 Errores y registro · V8 Protección de datos · V9 Comunicaciones · V10 Código malicioso · V12 Archivos y recursos · V14 Configuración. V2 Autenticación, V3 Sesiones, V4 Control de acceso, V6 Cifrado en reposo y V13 APIs no aplicables: no hay login, sesión, recurso protegido, dato en reposo ni API de servidor en el origen público.

NIST SP 800-218 SSDF v1.1

Prepare: requisitos y roles definidos. Protect: repositorio de fuentes privado, toolchain fijada, builds reproducibles y sin símbolos, sin source maps ni rutas de depuración. Produce: puertas SHA-256 registradas y revisión antes de la promoción. Respond: conservación de evidencia, registro de negativos y contacto privado de divulgación.

NIS2

Gestión de riesgos, seguridad de la cadena de suministro, notificación de incidentes y responsabilidad se abordan de forma proporcionada para un pequeño piloto de investigación. La aplicabilidad legal depende de la clasificación de la entidad y la jurisdicción; no se reclama cumplimiento.

Límites honestos

Ningún código de cliente ni módulo compilado es imposible de reverse-engineer. Quitar símbolos aumenta el coste, no la imposibilidad. La propiedad defendible: ninguna fuente en el origen público.

GitHub Pages ignora _headers en el plan gratuito; no se pueden fijar cabeceras HTTP. Una meta-CSP está incluida y es parcial. Los archivos cargados permanecen en memoria en el navegador y nunca se transmiten.
