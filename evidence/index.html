Method

  • SRD and paq8px v217 −8 were run on the same x86-64 Linux machine with AVX2; the published SRD figures used 2 cores and 6 GB.
  • SRD was built with cc -O2 -march=native -ffp-contract=off -pthread and run as SRD c in out, then SRD d in out in a new process.
  • Time is the wall-clock time of the whole command, including every internal trial. Decode time is measured separately.
  • Memory is the peak resident set of the largest process (GNU time %M). Trials can run as parallel processes, so the machine-wide total at one moment can be higher.
  • cmix v21 figures are published values and were not re-run here.
  • pic (Calgary) and ptt5 (Canterbury) are the same file (identical SHA-256) and appear under both corpora.
  • Input and artifact SHA-256 values are in the CSV where they were recorded.

What counts as a result

Exact restore, a matching SHA-256 and declared comparator provenance. PAQ is measured here; every cmix figure is published, unverified and does not count toward a record.
