Häufige Fragen

Klare Antworten.

Was öffentlich ist, was privat bleibt und wie SRD ohne Quelloffenlegung geprüft wird.

Wird eine hochgeladene Datei an einen Server gesendet?

Der öffentliche Kompressor ist gesperrt, daher lädt diese statische Seite keine Datei hoch. Private Evaluationen laufen serverseitig unter separaten Kontrollen.

Wird der Quellcode der Engine veröffentlicht?

Nein. Die öffentliche Origin enthält nur vorgebaute statische Dateien. Keine Quellen, Build-Skripte, Debugdaten oder ausführbaren Codec.

Wird ein ausführbarer Codec an den Browser geliefert?

Nein. Die öffentliche Origin ist rein statisch. Produktionsfähigkeiten bleiben serverseitig und sind nur über private Evaluation oder lizenzierte Bereitstellung verfügbar.

Wie erhalte ich stärkere Produktionskonfigurationen?

Über eine Evaluierung unter NDA oder einen lizenzierten Einsatz. Wir liefern Artefakte, SHA-256-Werte sowie gemessene Größe, Zeit und Speicher. Keine Quellen oder Implementierungsmetadaten werden offengelegt.

Wie wird ein Ergebnis geprüft?

Durch bytegenaue Wiederherstellung in einer separaten Dekodierung und passenden SHA-256 von Eingabe und wiederhergestellten Bytes. Bereits komprimierte Formate zeigen meist geringere Gewinne.

Private Installation nötig?

Kontaktieren Sie uns für einen On-Prem-Build oder eine gezielte Forschungszusammenarbeit.
