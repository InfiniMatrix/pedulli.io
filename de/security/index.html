Start / Sicherheit
Sicherheit

Kein Quellcode auf der öffentlichen Origin.

Der Browser erhält nur vorgebautes HTML, CSS, JavaScript und ein symbolbereinigtes WebAssembly-Modul. Quellen, Build-Skripte, Debugdaten und Implementierungsmetadaten bleiben privat.

Statische Origin

GitHub Pages liefert nur Dateien. Kein Servercode, keine Datenbank, kein Login, keine Geheimnisse.

Bereinigtes Modul

Das WebAssembly hat keine Debug-Sektionen, keine Namenssektion und keine Producer-Metadaten.

Undurchsichtige Fehler

Nur generische Meldungen — keine Version, Ebene, Pfad oder Kette.

OWASP ASVS 4.0

V1 Architektur und Threat Modeling · V5 Validierung und Encoding · V7 Fehler und Logging · V8 Datenschutz · V9 Kommunikation · V10 Schadcode · V12 Dateien und Ressourcen · V14 Konfiguration. V2 Authentifizierung, V3 Sitzungen, V4 Zugriffskontrolle, V6 Verschlüssetzung im Ruhezustand und V13 APIs nicht anwendbar: kein Login, keine Sitzung, keine geschützte Ressource, keine Daten im Ruhezustand und keine Server-API auf der öffentlichen Origin.

NIST SP 800-218 SSDF v1.1

Prepare: definierte Sicherheitsanforderungen und Rollen. Protect: privates Quellrepository, festgelegte Toolchain, reproduzierbare bereinigte Builds, keine Source Maps oder Debug-Routen. Produce: erfasste SHA-256-Gates und Prüfung vor der Promotion. Respond: Beweissicherung, Negativprotokoll und privater Offenlegungskontakt.

NIS2

Risikomanagement, Lieferkettensicherheit, Incident Reporting und Rechenschaft werden angemessen für ein kleines Forschungsprojekt behandelt. Die rechtliche Anwendbarkeit hängt von Einstufung und Jurisdiktion ab; keine Konformität wird behauptet.

Ehrliche Grenzen

Kein clientseitiger Code und kein kompiliertes Modul ist unmöglich zu reverse-engineern. Bereinigung erhöht die Kosten, nicht die Unmöglichkeit. Die verteidigbare Eigenschaft: kein Quellcode auf der öffentlichen Origin.

GitHub Pages ignoriert _headers im kostenlosen Tarif; HTTP-Sicherheitsheader können dort nicht gesetzt werden. Eine Meta-CSP ist enthalten und teilweise wirksam. Hochgeladene Dateien bleiben im Browser-Speicher und werden nie übertragen.
