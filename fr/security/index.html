Sécurité

Aucune source sur l’origine publique.

Le navigateur reçoit seulement du HTML, CSS et JavaScript préconstruits. Sources, scripts de build, débogage et métadonnées restent privés; aucun codec exécutable n’est livré.

Origine statique

GitHub Pages ne sert que des fichiers ; aucun code serveur, base de données, login ou secret.

Aucun codec client

Aucun compresseur, modèle, primer ou poids exécutable n’est présent sur l’origine publique.

Erreurs opaques

Messages génériques uniquement — aucune version, niveau, chemin ou chaîne.

OWASP ASVS 4.0

V1 Architecture et modélisation des menaces · V5 Validation et encodage · V7 Erreurs et journalisation · V8 Protection des données · V9 Communications · V10 Code malveillant · V12 Fichiers et ressources · V14 Configuration. V2 Authentification, V3 Sessions, V4 Contrôle d’accès, V6 Chiffrement au repos et V13 API non applicables : aucun login, session, ressource protégée, donnée au repos ou API serveur sur l’origine publique.

NIST SP 800-218 SSDF v1.1

Prepare : exigences et rôles définis. Protect : dépôt source privé, chaîne d’outils épinglée, builds reproductibles et nettoyés, aucune source map ni route de débogage. Produce : portes SHA-256 enregistrées et revue avant promotion. Respond : conservation des preuves, journal des négatifs et contact de divulgation privé.

NIS2

Gestion des risques, sécurité de la chaîne d’approvisionnement, signalement des incidents et responsabilité sont traités de façon proportionnée pour un petit pilote de recherche. L’applicabilité légale dépend de la classification de l’entité et de la juridiction ; aucune conformité n’est revendiquée.

Limites honnêtes

Aucun code client ni module compilé n’est impossible à rétro-ingénierer. Le nettoyage augmente le coût, pas l’impossibilité. La propriété défendable : aucune source sur l’origine publique.

GitHub Pages ignore _headers sur l’offre gratuite : les en-têtes HTTP ne peuvent pas être définis. Une meta-CSP est incluse et partielle. La démo statique verrouillée ne téléverse aucun fichier.
