Technology

One engine. One mode.

SRD is a deterministic lossless codec. The public surface exposes one choice and reports size, time and memory together.

Deterministic

For a fixed engine version and settings, the same input bytes always produce the same artifact.

Separate verification

The decoder runs in a fresh process and never reuses encoder state. It is the same codebase, not an independent implementation.

Hash gate

Input and restored bytes must produce the same SHA-256.

What we publish

Only verified measurements and the conditions that produced them. Methods, models and unpublished results remain private intellectual property.
