# Pedulli.io v2

Static site. No framework and no build step.

Production deployment target:
- Cloudflare DNS
- New VPS/static host
- HTTPS
- nginx or equivalent

Before deployment:
1. Confirm domain control.
2. Create a complete backup of any existing site.
3. Configure HTTPS.
4. Upload this directory as the document root.
5. Verify all pages and mobile layout.
