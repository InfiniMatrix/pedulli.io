Domande frequenti

Risposte chiare.

Cosa è pubblico, cosa resta privato e come valutare SRD senza divulgare il sorgente.

Il caricamento invia il file a un server?

Questo sito non carica nulla. Le valutazioni private si svolgono sul server privato di Cristallo Technologies: inviate sotto NDA i file che scegliete, e per quanto tempo vengono conservati e quando vengono cancellati si concorda per iscritto prima dell'inizio della valutazione.

Il sorgente del motore è pubblicato?

No. L’origine pubblica contiene solo file statici precompilati. Nessun sorgente, script di build, dato di debug o codec eseguibile è presente.

Viene distribuito un codec eseguibile al browser?

No. Il sito pubblico è solo statico. Il motore gira solo sul server privato di Cristallo Technologies, per valutazioni private e uso su licenza.

Come accedo alle configurazioni di produzione più potenti?

Tramite una valutazione sotto NDA o un deployment licenziato. Restituiamo artifact, valori SHA-256 e dimensione, tempo e memoria misurati. Nessun sorgente o metadato implementativo viene divulgato.

Come viene verificato un risultato?

Con ripristino byte-exact in una decodifica separata e SHA-256 corrispondente tra input e byte ripristinati. I formati già compressi mostrano generalmente guadagni minori.

Serve un deploy privato?

Contattaci per una build on-prem o una collaborazione di ricerca mirata.
