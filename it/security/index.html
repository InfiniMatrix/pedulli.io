Sicurezza

Nessun sorgente sull’origine pubblica.

Il browser riceve solo HTML, CSS e JavaScript precompilati. Sorgenti, script di build, debug e metadati restano privati; nessun codec eseguibile viene distribuito.

Origine statica

GitHub Pages serve solo file. Nessun codice server, database, login o segreto.

Nessun codec client

Nessun compressore, modello, primer o peso eseguibile è presente sull’origine pubblica.

Errori opachi

Solo messaggi generici: nessuna versione, livello, percorso o catena.

OWASP ASVS 4.0

V1 Architettura e threat modeling · V5 Validazione ed encoding · V7 Errori e logging · V8 Protezione dati · V9 Comunicazioni · V10 Codice malevolo · V12 File e risorse · V14 Configurazione. V2 Autenticazione, V3 Sessioni, V4 Controllo accessi, V6 Crittografia a riposo e V13 API non applicabili: nessun login, sessione, risorsa protetta, dato a riposo o API server sull’origine pubblica.

NIST SP 800-218 SSDF v1.1

Prepare: requisiti e ruoli definiti. Protect: repository sorgente privato, toolchain pinned, build riproducibili con stripping, nessuna source map o route di debug. Produce: gate SHA-256 registrati e revisione prima della promozione. Respond: conservazione delle evidenze, log dei negativi e contatto di divulgazione privato.

NIS2

Gestione del rischio, sicurezza della supply chain, segnalazione degli incidenti e responsabilità sono affrontate in modo proporzionato a un piccolo pilota di ricerca. L’applicabilità legale dipende dalla classificazione dell’entità e dalla giurisdizione; non è dichiarata conformità.

Limiti onesti

Nessun codice lato client o modulo compilato è impossibile da reverse-engineer. Lo stripping alza il costo, non l’impossibilità. La proprietà difendibile è che nessun sorgente è presente sull’origine pubblica.

GitHub Pages ignora _headers sul piano gratuito: gli header HTTP non possono essere impostati. Una meta CSP è inclusa ed è parziale. La demo statica bloccata non carica file.
