FAQ

Clear answers.

What is public, what stays private, and how to evaluate SRD without source disclosure.

Does uploading a file send it to a server?

The public compressor is locked, so no file is uploaded by this static site. Private evaluations run server-side under separate controls.

Is the system source code published?

No. The public origin serves only prebuilt static files. No source, build files, debug data or executable implementation are present.

Is an executable implementation shipped to the browser?

No. The public origin is static only. Production capability remains server-side and is available through private evaluation or licensed deployment.

How do I access stronger production configurations?

Through an NDA evaluation or a licensed deployment. We return artifacts, SHA-256 values and measured size, time and memory. No source or implementation metadata is disclosed.

How is a result verified?

By byte-exact restore in a separate decode and a matching SHA-256 of input and restored bytes. Already-compressed formats usually show smaller gains.

Contact us for an on-prem build or a scoped research collaboration.
